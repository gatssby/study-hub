> For agentic workers: use executing-plans task-by-task. User explicitly selected autonomous execution; do not pause for secondary design decisions.

Goal: retire classified legacy infrastructure and run independent FO collection/content services without real transcription.
Architecture: extract proven portal and video core into federal-online; independent SQLite metadata/content API and disabled transcription queue; keep Anki vNext intact.
Tech Stack: Python, Playwright, SQLite, FastAPI, FFmpeg, rclone, systemd.
Spec: docs/superpowers/specs/2026-10-21-study-hub-design.md

## Global Constraints
- TRANSCRIPTION_ENABLED=false, no real ASR, no automatic activation, no Mac inference.
- No backups; no indiscriminate deletion; preserve originals, Anki vNext, sessions and GPT knowledge.
- Public GitHub: never version runtime data or signed URLs/secrets.
- Preserve preexisting dirty workspace changes.

## Review Focus
- Login expiry and incomplete traversal must not produce removal or empty authoritative catalog.
- New course/year/category must not be blocked by 2026 identifiers or category allowlists.
- Signed URL rotation must not masquerade as content deletion.
- Disk exhaustion and unverified upload must not lose local originals.
- Accidental service start must not start ASR.
